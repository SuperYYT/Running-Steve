# v3.4.4 · 夜间可读性 · 跳中下蹲 · 性能

## Report

## [S1] Problem
1. 日夜循环的夜晚过暗，障碍与道路几乎不可辨，极易失败；路灯仅有发光方块、无照明感。
2. 起跳后无法打断：空中按下蹲只在落地后生效，不符合「打断跳跃、快速下蹲」的物理直觉。
3. 需整体审视运行效率（灯光、装饰材质、每帧分配）。

## [S2] Design

### 夜间照明
| 项 | 白天 | 夜晚（调整后） |
| --- | --- | --- |
| Hemisphere | 1.55 | **1.25**（冷月色 #8a9cc8 / 地面 #2a3348） |
| Directional | 2.4 | **1.1**（月光 #b8c8ff） |
| 背景/雾 | #87d4ef | **#243352**，雾 28–85（更远） |
| 路灯 | 白天火把 | 夜晚暖黄灯罩 + **地面光斑**（廉价假光） |

路灯装饰：提高 `emissiveIntensity`；每个灯柱下增加半透明黄光圆盘（`MeshBasicMaterial` additive），随灯显隐。再加 **2 个 PointLight** 池，每帧吸附到最近两个可见灯，提供真实受光（预算内 ≤3 点光）。

### 跳中下蹲（物理直觉）
- 空中按蹲：**打断上升**（`vy = min(vy, 0) - 10`）+ 额外重力 → 快速砸地
- 落地立刻进入点按下蹲（`pendingDuck`），无起身锁
- 原有：跳跃取消下蹲；落地滑铲保留

### 性能
- `Track.mat` 材质缓存（同色参数复用）
- 夜间光斑/灯罩共享几何
- 不新增每帧 Vector 分配；维持障碍 `built` 网格缓存
- 验证：build + test + inspector renderBudget 不超限

## [S3] Out of Scope

- 多局天气系统
