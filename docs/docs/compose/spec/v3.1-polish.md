### 反作弊契约

- `POST /api/runs/start`（登录）→ `{ runId, token }`（30 分钟有效）
- `POST /api/scores` 需 `runToken`；校验：
  - `durationMs` 2s–2h
  - `distance ≤ maxSpeed(22) * durationSec * 1.25 + 40`
  - `maxCombo ≤ 12 + durationSec * 6`
  - `cookies+cakes ≤ 8 + durationSec * 8`
  - 无 token / 过期 / 二次使用 → 403
- 榜：`best_distance`、`best_combo`（不再有 best_score）

### API 变更

- `GET /api/me` → 含 `bestDistance, bestCombo, lastDistance, lastCombo, runCount`
- `POST /api/scores` body `{ runToken, distance, maxCombo, durationMs, cookies, cakes, failReason? }`
- `GET /api/leaderboard` → `{ distance: Top50, combo: Top50 }`
